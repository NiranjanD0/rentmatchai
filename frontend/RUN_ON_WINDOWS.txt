RENTMATCH AI PROTOTYPE — WINDOWS QUICK START

1. Install Node.js LTS if needed: https://nodejs.org
2. Extract the ZIP.
3. Open Command Prompt / PowerShell in the RentMatchAI_Prototype folder.
4. Run:
   npm install
   npm run dev
5. Open the localhost URL printed by Vite.

To test a production build:
   npm run build

NOTE: This is a frontend prototype. Listings and match scores are sample data.
No AI model, backend API, PostgreSQL database, map API, or real owner contact is connected yet.
