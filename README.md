# RentMatchAI

### AI-Powered Personalized Rental Assistant

RentMatchAI is an AI-powered rental assistance platform designed to help
students, working professionals, and families find rental properties that
better match their individual needs, lifestyle, budget, and commute
requirements.

Instead of relying only on traditional filters, RentMatchAI allows users to
describe their ideal home in natural language. The system analyzes the user's
requirements, converts them into meaningful preferences, and recommends
suitable rental properties based on those preferences.

RentMatchAI also assists users during the property evaluation process by
generating personalized questions that they can ask landlords during property
visits.

# Project Overview

Finding a suitable rental property can be difficult because users often have
multiple requirements that are not easily represented using conventional
property-search filters.

A user may care about:

- Monthly rent
- Security deposit
- Property type
- Number of bedrooms
- Furnishing
- Location
- Distance from college or workplace
- Commute time
- Transportation availability
- Amenities
- Parking
- Lifestyle preferences
- Family/student/professional suitability

RentMatchAI aims to simplify this process by allowing users to communicate
their requirements naturally and receive personalized property
recommendations.

### Example

A user can enter:

> "I am a student looking for a furnished 1 BHK near my university.
> My budget is around ₹15,000 per month and I don't have a vehicle, so
> I would prefer a place with good public transport and a short commute."

RentMatchAI analyzes the request and identifies relevant preferences such as:

```text
User Type       : Student
Property Type   : 1 BHK
Budget          : ₹15,000/month
Furnishing      : Furnished
Transportation  : Public Transport
Commute         : Short
Location        : Near University
